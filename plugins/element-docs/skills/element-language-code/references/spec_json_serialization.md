# Спецификация JSON-сериализации Element 9.2

Сводная спецификация JSON-механизмов серверного кода Element через `Стд::Json`. Составлена по HTML-документации и примерам из `data/temp/pages/json-stdlib` и `data/temp/pages/json-guide`.

- Область действия

## Область действия

Описано:

- объектная сериализация и десериализация;
- потоковое чтение и запись;
- смешанный режим;
- настройки чтения/записи;
- аннотации сопоставления модели и JSON;
- перечисления форматов и режимов;
- исключения чтения и записи.

## Основные типы

| Тип | Назначение |
|---|---|
| `СериализацияJson` | Тип-одиночка для чтения/записи объектов JSON целиком. |
| `ЧтениеJson` | Потоковое чтение JSON. |
| `ЗаписьJson` | Потоковая запись JSON. |
| `НастройкиЧтенияОбъектовJson` | Настройки десериализации объектов. |
| `НастройкиЗаписиОбъектовJson` | Настройки сериализации объектов; расширяют настройки записи JSON. |
| `НастройкиЗаписиJson` | Настройки низкоуровневой записи JSON. |
| `JsonОбъект` | Аннотация структуры. |
| `JsonСвойство` | Аннотация поля: имя, raw-запись, псевдонимы. |
| `JsonИгнорироватьСвойство` | Аннотация поля, исключающая его из JSON. |
| `JsonЭлементПеречисления` | Аннотация элемента перечисления: имя и псевдонимы. |
| `ВидУзлаJson` | Вид текущего узла при потоковом чтении. |
| `РежимЗаписиТипаJson` | Режим записи информации о типе. |
| `ФорматМоментаJson` | Формат записи `Момент`. |
| `ПереносСтрокJson` | Режим переносов строк. |
| `ЭкранированиеСимволовJson` | Режим экранирования символов. |
| `ИсключениеЧтенияJson` | Ошибка чтения JSON. |
| `ИсключениеЗаписиJson` | Ошибка записи JSON. |

## Выбор режима

| Режим | Типы | Когда использовать |
|---|---|---|
| Объектный | `СериализацияJson` | Небольшой payload с известной структурой; нужно получить или записать типизированный объект. |
| Потоковый | `ЧтениеJson`, `ЗаписьJson` | Большой JSON, частичная обработка или ручное управление структурой. |
| Смешанный | `ЧтениеJson`/`ЗаписьJson` + `СериализацияJson` | Нужно пройти потоком до узла или записать обертку, а вложенный фрагмент обработать объектной сериализацией. |

## СериализацияJson

`СериализацияJson` доступен на сервере и читает/записывает объекты JSON целиком.

### Запись

```xbsl
ЗаписатьОбъект(
  Значение: Объект?,
  Настройки: НастройкиЗаписиОбъектовJson
): Строка

ЗаписатьОбъект(
  Приемник: ПотокЗаписи|ЗаписьJson,
  Значение: Объект?,
  Настройки: НастройкиЗаписиОбъектовJson)
```

Если приемник — `ЗаписьJson`, объект записывается в поток, с которым создан writer.

### Чтение

```xbsl
ПрочитатьОбъект<ТипОбъекта>(
  Источник: ПотокЧтения|ЧтениеJson|Строка,
  Тип: Тип<ТипОбъекта>,
  Настройки: НастройкиЧтенияОбъектовJson,
  Кодировка: Кодировка|Строка = Кодировка.Utf8
): ТипОбъекта
```

### Устаревшие методы

Сохранены для совместимости, в новых сценариях использовать типизированный `ПрочитатьОбъект<ТипОбъекта>(...)`.

```xbsl
ПрочитатьМассив(Источник: ПотокЧтения|Строка, Кодировка = Кодировка.Utf8): Массив<Объект?>
ПрочитатьСоответствие(Источник: ПотокЧтения|Строка, Кодировка = Кодировка.Utf8): Соответствие<Строка, Объект?>
ПрочитатьОбъект(Источник, Тип: Коллекция<Тип>, Настройки, Кодировка): Объект?
```

## Поддерживаемые типы

| Группа | Типы и правила |
|---|---|
| Модели | Структуры, объявленные в коде; перечисления. |
| Коллекции | `Массив`, `Множество`, `Соответствие`. |
| Простые типы | `Строка`, `Число`, `Булево`, `Неопределено`/`null`. |
| Дата и время | `Момент`, `ДатаВремя`, `Дата`, `Время`, `Длительность`. |
| Прочие значения | `Ууид`, `Версия`, `Байты`. |

При нетипизированном чтении JSON разбирается в `Число`, `Булево`, `Неопределено`, `Строка`, `Массив` или `Соответствие`. При типизированном чтении явно указанные простые типы имеют приоритет; если значение подходит под несколько типов, возникает исключение о неявном чтении.

## ЧтениеJson

`ЧтениеJson` доступен на сервере и предназначен для потокового чтения.

### Конструкторы

```xbsl
ЧтениеJson(Источник: Строка)
ЧтениеJson(Источник: ПотокЧтения, Кодировка: Кодировка|Строка = Кодировка.Utf8)
```

### Свойства

| Свойство | Тип | Назначение |
|---|---|---|
| `ВидУзла` | `ВидУзлаJson?` | Вид текущего JSON-узла. `Неопределено` до начала и после конца чтения. |
| `Значение` | `Строка` | Текстовое значение текущего узла. Для комментариев пустая строка. |
| `ТекущаяСтрока` | `Число` | Текущая строка, нумерация с 1. |
| `ТекущийСтолбец` | `Число` | Текущий столбец, нумерация с 1. |

### Навигация и чтение

```xbsl
Следующий(): Булево
ПрочитатьСодержимое<ТипОбъекта>(Настройки: НастройкиЧтенияОбъектовJson): ТипОбъекта
ПрочитатьСодержимоеКакСтроку(): Строка
ПрочитатьСодержимоеКакЧисло(): Число
ПрочитатьСодержимоеКакБулево(): Булево
ПрочитатьСодержимоеКакБайты(): Байты
ПрочитатьСодержимоеКакБайтыBase64(): Байты
ПрочитатьСодержимоеКакДата(ИгнорироватьВремя: Булево = Ложь): Дата
ПрочитатьСодержимоеКакВремя(ИгнорироватьДату: Булево = Ложь): Время
ПрочитатьСодержимоеКакДатаВремя(): ДатаВремя
ПрочитатьСодержимоеКакДлительность(): Длительность
ПрочитатьСодержимоеКакМомент(): Момент
ПрочитатьСодержимоеКакУуид(): Ууид
ПрочитатьСодержимоеКакМассив(): Массив<Объект?>
ПрочитатьСодержимоеКакСоответствие(): Соответствие<Строка, Объект?>
```

Методы чтения требуют, чтобы `Следующий()` уже был вызван и чтение не было завершено. Несоответствие ожидаемому типу или структуре приводит к `ИсключениеЧтенияJson`.

Однострочные комментарии JSON5 `//` поддерживаются при чтении, игнорируются и не попадают в результат.

## ЗаписьJson

`ЗаписьJson` доступен на сервере и предназначен для потоковой записи.

### Конструктор

```xbsl
ЗаписьJson(
  Поток: ПотокЗаписи,
  НастройкиЗаписи: НастройкиЗаписиJson,
  Кодировка: Кодировка|Строка = Кодировка.Utf8)
```

### Методы

```xbsl
Записать(Значение: Булево|Байты|Число|Строка|Дата|ДатаВремя|Длительность|Момент|Время|Ууид|Версия|?): ЗаписьJson
Записать(ИмяСвойства: Строка, Значение: Булево|Байты|Число|Строка|Дата|ДатаВремя|Длительность|Момент|Время|Ууид|Версия|?): ЗаписьJson
ЗаписатьNull(): ЗаписьJson
ЗаписатьNull(ИмяСвойства: Строка): ЗаписьJson
ЗаписатьБезОбработки(Текст: Строка): ЗаписьJson
ЗаписатьИмяСвойства(ИмяСвойства: Строка): ЗаписьJson
ЗаписатьНачалоОбъекта(): ЗаписьJson
ЗаписатьКонецОбъекта(): ЗаписьJson
ЗаписатьНачалоМассива(): ЗаписьJson
ЗаписатьКонецМассива(): ЗаписьJson
```

### Форматы записи значений

| Тип | JSON-представление |
|---|---|
| `Булево` | JSON boolean. |
| `Байты` | Строка base64. |
| `Неопределено` | `null`. |
| `ДатаВремя` | ISO-8601 `"гггг-ММ-дд'T'ЧЧ:мм:сс.ССС"`. |
| `Дата` | `"YYYY-MM-DD"`. |
| `Время` | `"ЧЧ:мм:сс.ССС"`. |
| `Длительность` | ISO-8601 duration. |
| `Момент` | Согласно `НастройкиЗаписиJson.ФорматМомента`. |

## Настройки

### НастройкиЗаписиJson

```xbsl
НастройкиЗаписиJson()
```

| Свойство | Тип | Назначение |
|---|---|---|
| `ПереносСтрок` | `ПереносСтрокJson` | Режим переводов строк. |
| `ПроверятьСтруктуру` | `Булево` | Проверять корректность структуры JSON при записи. |
| `СимволыОтступа` | `Строка` | Символы отступа. |
| `ФорматМомента` | `ФорматМоментаJson` | Формат записи `Момент`. |
| `ЭкранированиеСимволов` | `ЭкранированиеСимволовJson` | Режим экранирования. |
| `ЭкранироватьАмперсанд` | `Булево` | Экранировать `&`. |
| `ЭкранироватьОдинарныеКавычки` | `Булево` | Экранировать `'`. |
| `ЭкранироватьРазделителиСтрокИАбзацев` | `Булево` | Экранировать line/paragraph separators. |
| `ЭкранироватьСлеш` | `Булево` | Экранировать `/`. |
| `ЭкранироватьУгловыеСкобки` | `Булево` | Экранировать `<` и `>`. |

### НастройкиЗаписиОбъектовJson

```xbsl
НастройкиЗаписиОбъектовJson()
```

| Свойство | Тип | Назначение |
|---|---|---|
| `ИгнорируемыеСвойства` | `Соответствие<Тип, Множество<Строка>>` | Поля, не записываемые в JSON. |
| `ИспользуемыеИменаСвойств` | `Соответствие<Тип, Соответствие<Строка, Строка>>` | Внешние JSON-имена свойств. |
| `ПропускатьНеопределено` | `Булево?` | Не записывать `Неопределено`. |
| `ПропускатьПустыеКоллекции` | `Булево?` | Не записывать пустые коллекции. |
| `РежимЗаписиТипа` | `РежимЗаписиТипаJson?` | Управляет записью информации о типе. |
| `СвойстваЗаписываемыеБезОбработки` | `Соответствие<Тип, Множество<Строка>>` | Свойства, записываемые как raw JSON. |

### НастройкиЧтенияОбъектовJson

```xbsl
НастройкиЧтенияОбъектовJson()
```

| Свойство | Тип | Назначение |
|---|---|---|
| `ИгнорироватьЛишниеЧастиДатыВремени` | `Булево` | Разрешает игнорировать лишние части даты/времени при чтении. |
| `ИгнорироватьНеизвестныеСвойства` | `Булево?` | Игнорировать поля JSON, отсутствующие в целевом типе. |
| `ИнициализироватьОтсутствующиеПоля` | `Булево?` | Заполнять отсутствующие поля значениями по правилам инициализации. |
| `ИнициализироватьПустыеКоллекции` | `Булево?` | Инициализировать пустые коллекции. |
| `ПсевдонимыСвойств` | `ЧитаемоеСоответствие<Тип, Соответствие<Строка, Множество<Строка>>>` | Альтернативные имена JSON-свойств при чтении. |

При включенной инициализации отсутствующих полей применяется первый доступный вариант: значение из JSON, значение по умолчанию поля, `Неопределено` для nullable-типа, значение типа по умолчанию. Если ничего не подходит, возникает исключение чтения JSON.

## Аннотации

| Аннотация | Где применяется | Параметры и эффект |
|---|---|---|
| `JsonИгнорироватьСвойство` | Поле структуры | Не записывает поле; при чтении поле получает значение по умолчанию, если оно возможно. Эквивалентно `НастройкиЗаписиОбъектовJson.ИгнорируемыеСвойства`. |
| `JsonОбъект` | Структура | `ПропускатьПустыеЗначения`, `РежимЗаписиТипа`, `ИгнорироватьНеизвестные`; задает объектные настройки на уровне типа. |
| `JsonСвойство` | Поле структуры | `Имя`, `БезОбработки`, `Псевдонимы`; управляет внешним именем, raw-записью и альтернативными именами при чтении. |
| `JsonЭлементПеречисления` | Элемент перечисления | `Имя`, `Псевдонимы`; управляет JSON-представлением значения перечисления. |

Аннотации можно задавать как в `.xbsl`, так и в YAML-описании элемента. Это удобно для структур, у которых внешние JSON-имена отличаются от русских имен полей.

## Практические паттерны

### Динамический JSON внешнего API

Если структура ответа внешнего API большая или меняется, читайте ее в `Тип<Объект>` и явно приводите вложенные части перед индексированием.

```xbsl
знч ТелоОтвета = ОтветХттп.Тело.ПрочитатьКакСтроку()
знч Ответ = СериализацияJson.ПрочитатьОбъект(ТелоОтвета, Тип<Объект>) как неизвестно

знч Текст = Ответ["choices"][0]["message"]["content"] как Строка
знч Токены = Ответ["usage"]["completion_tokens"] как Число
```

Для JSON-RPC и похожих протоколов, где верхний уровень известен, но `params`/`result` произвольные, используйте `Соответствие<Строка, Объект?>`:

```xbsl
знч Сообщение = СериализацияJson.ПрочитатьОбъект(
    ТелоСтрокой,
    Тип<Соответствие<Строка, Объект?>>)

знч Ид = Сообщение.ПолучитьИлиНеопределено("id") как Число?
знч Метод = Сообщение.ПолучитьИлиУмолчание("method", "") как Строка
знч Параметры = Сообщение.ПолучитьИлиНеопределено("params") как Соответствие<Строка, Объект?>?
```

### Типизированные параметры функций

Для аргументов LLM-инструментов и других schema-driven JSON лучше объявлять структуру и перечисления, а не разбирать все через `Объект`.

```xbsl
перечисление РежимПолученияЦелей
    @JsonЭлементПеречисления("by_id")
    ПоИд

    @JsonЭлементПеречисления("list")
    Список

    @JsonЭлементПеречисления("search")
    Поиск
;

структура ПараметрыПолученияЦелей
    @JsonСвойство("mode")
    обз знч Режим: РежимПолученияЦелей

    @JsonСвойство("goal_id")
    знч ИдЦели: Строка?

    @JsonСвойство("query")
    знч Запрос: Строка?
;

знч Параметры = СериализацияJson.ПрочитатьОбъект(
    ПараметрыСтрокой,
    Тип<ПараметрыПолученияЦелей>)
```

Так внешние имена остаются в контракте API (`mode`, `goal_id`, `by_id`), а код работает с доменными русскими именами.

### Неполный или расширяемый JSON

Когда источник может не передать часть полей или добавить новые, настройте чтение перед десериализацией.

```xbsl
знч Настройки = новый НастройкиЧтенияОбъектовJson()
Настройки.ИнициализироватьОтсутствующиеПоля = Истина
Настройки.ИгнорироватьНеизвестныеСвойства = Истина

знч Параметры = СериализацияJson.ПрочитатьОбъект(
    ПараметрыСтрокой,
    Тип<ПараметрыИнструмента>,
    Настройки)
```

`ИнициализироватьОтсутствующиеПоля` полезно для optional-полей и значений по умолчанию. Для обязательных полей без допустимого значения по умолчанию ошибка чтения остается корректным поведением.

### Коллекции как сохраняемый JSON

Для хранения в строковом поле или передачи между компонентами можно сериализовать типизированные коллекции и читать их обратно тем же типом.

```xbsl
метод ВСтроку(Вектор: Массив<Число>): Строка
    возврат СериализацияJson.ЗаписатьОбъект(Вектор)
;

метод ИзСтроки(ВекторСтрокой: Строка): Массив<Число>
    возврат СериализацияJson.ПрочитатьОбъект(ВекторСтрокой, Тип<Массив<Число>>)
;
```

Тот же подход работает для массивов структур:

```xbsl
знч Интервалы = СериализацияJson.ПрочитатьОбъект(
    РабочиеИнтервалыСтрокой,
    Тип<Массив<ГрафикиРаботы.ИнтервалВремени>>)
```

### Формирование JSON-ответа

JSON-литералы Element сериализуются напрямую: `Истина/Ложь` становятся JSON boolean, `Неопределено` становится `null`, массивы и соответствия становятся JSON array/object.

```xbsl
знч Ответ = {
    "jsonrpc": "2.0",
    "id": Ид,
    "result": {
        "content": [{
            "type": "text",
            "text": Результат.Текст
        }],
        "isError": Результат.Ошибка
    }
}

знч ОтветСтрокой = СериализацияJson.ЗаписатьОбъект(Ответ)
```

## Перечисления

| Перечисление | Значения |
|---|---|
| `ВидУзлаJson` | `Null`, `Булево`, `Строка`, `Число`, `ИмяСвойства`, `Комментарий`, `НачалоМассива`, `КонецМассива`, `НачалоОбъекта`, `КонецОбъекта`. |
| `РежимЗаписиТипаJson` | `НеЗаписывать`, `ЗаписыватьВсегда`, `ЗаписыватьПриНеоднозначности`. |
| `ФорматМоментаJson` | `Iso`, `JavaScript`, `Microsoft`. |
| `ПереносСтрокJson` | `Отсутствует`, `Unix`, `Windows`. |
| `ЭкранированиеСимволовJson` | `Отсутствует`, `СимволыВнеAscii`, `СимволыВнеBmp`. |

## Инварианты

- Основные JSON-типы доступны на сервере.
- Для больших JSON-документов предпочтителен потоковый режим.
- В облаке есть ограничение на чтение/запись потока целиком 10 Мбайт.
- `ЧтениеJson` требует `Следующий()` перед чтением значения.
- `ЗаписьJson` может проверять структуру, если включено `ПроверятьСтруктуру`.
- Raw-запись через `ЗаписатьБезОбработки` и `СвойстваЗаписываемыеБезОбработки` требует корректного JSON-фрагмента.
- Для несовпадающих внешних имен JSON используйте настройки или аннотации, а не ручное переименование после чтения.

## Связь с HTTP

JSON-механизмы не выполняют HTTP-запросы.

Для исходящего JSON API сериализуйте объект в строку или поток, задайте `ЗапросHttp.УстановитьТипСодержимого("application/json")`, передайте данные через `ЗапросHttp.УстановитьТело(...)`, затем читайте `ОтветHttp.Тело` и десериализуйте его через `СериализацияJson` или `ЧтениеJson`.

```xbsl
исп ОтветХттп = КлиентHttp
    .ЗапросPost("https://api.example.com/v1/responses")
    .УстановитьТипСодержимого("application/json")
    .УстановитьТело(СериализацияJson.ЗаписатьОбъект(Запрос))
    .Выполнить()

знч Ответ = СериализацияJson.ПрочитатьОбъект(
    ОтветХттп.Тело.ПрочитатьКакСтроку(),
    Тип<Объект>)
```

Для входящего HTTP-сервиса сначала прочитайте тело запроса строкой, затем десериализуйте и явно задайте JSON-заголовок ответа:

```xbsl
знч ТелоСтрокой = Запрос.Тело.ПрочитатьКакСтроку()
знч Данные = СериализацияJson.ПрочитатьОбъект(ТелоСтрокой, Тип<Соответствие<Строка, Объект?>>)

Запрос.Ответ.Заголовки.Установить("Content-Type", "application/json")
Запрос.Ответ.УстановитьТело(СериализацияJson.ЗаписатьОбъект({"ok": Истина}))
```
